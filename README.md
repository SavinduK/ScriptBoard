# KeyPro Keyboard (Web Edition)

A high-performance, feature-packed Gboard-style virtual keyboard and management suite rewritten from Android (Jetpack Compose) into modern React + TypeScript + Vite.

## Features Preserved & Ported
- **Full Virtual Keyboard Layouts**:
  - Standard QWERTY Layout
  - Sinhala Wijesekara Layout with dynamic vowel modifier combination logic
  - Symbols Mode 1 (Numbers and common punctuation)
  - Symbols Mode 2 (Extended math and special characters)
  - Dedicated Number Row (toggleable)
  - Numpad Layout for rapid numeric entry
  - Extended PC Layout with function keys (F1–F12, Insert, Delete, PrintScreen, Pause, Home, End, PgUp, PgDn)
  - Laptop Navigation Keys Bar (Esc, Tab, Ctrl, Alt, Arrow navigation)
- **Interactive Test Keyboard Arena**:
  - Live typing area with real-time cursor navigation and text mutation
  - Multi-line editor testing with clear, copy, and preset prompt loader
  - Dynamic visual keycap previews with customizable font sizing (14px - 28px)
- **Clipboard & Quick Snippets Hub**:
  - Pinned quick snippets with custom trigger shortcuts for rapid text insertion
  - Clipboard history manager with search, category filtering, and direct copy/paste
  - Support for snippet creation, editing, pinning, and deletion
- **Rich Emoji, Kaomoji, Ancient Glyphs & Stickers**:
  - 8 standard emoji categories (Smileys, Gestures, Nature, Food, Travel, Objects, Symbols, Math)
  - Downloadable Ancient Emoji packs (Elder Futhark Runes, Egyptian Hieroglyphs, Japanese Kaomoji, Alchemical Symbols)
  - Animated WebP and GIF sticker drawer with custom sticker upload support
- **Language Packs Manager**:
  - Multi-language support (English, Sinhala Wijesekara, Tamil Anjal, Hindi Inscript, Spanish)
  - In-app pack downloading and dynamic layout switching
- **Audio & Haptic Feedback**:
  - Web Audio API synthesizer for tactile mechanical click and backspace sounds
  - Vibration API support for physical haptic feedback on supported mobile devices
- **Customizable Themes**:
  - GBoard Dark, GBoard Light, Cyber Navy, AMOLED Black, Sunset Coral, Emerald Mint
  - Full RGB Color Customization with live preview
